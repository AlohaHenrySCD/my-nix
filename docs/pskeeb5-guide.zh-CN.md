**pskeeb5 中文上手说明**

根据 2026-09-09 从你已连接的 pskeeb5 读取的 ZMK Studio 布局整理。适用于本次读取的配置；以后改键后需要同步更新。

先记住四件事：**短按打字；长按双功能键使用修饰键或切层；左拇指 Enter 长按进入数字层；右拇指退格长按进入符号层。** 方向键则用左拇指 Esc 长按进入导航层。

下文的字母一律指“基础层中该字母所在的物理位置”。例如“数字层按 U”指按原来 U 的位置，输出的是 7。

**认清基础布局**

这把键盘在 Studio 中有 38 个键位，左右各三排字母键、底部各四个键。以下按屏幕从左到右排列，未体现实际错列和旋转角度。

```text
左半边                         右半边
 Q   W   E   R   T              Y   U   I   O   P
 A   S   D   F   G              H   J   K   L   ;
 Z   X   C   V   B              N   M   ,   .   /

底部，从左到右：
 Power  Enter  Esc  鼠标右键     鼠标左键  退格  Space  播放/暂停
```

最靠近两半中间缝隙的两个斜键是鼠标键：左半边的为鼠标右键，右半边的为鼠标左键。

| 底部键的位置 | 短按 | 长按 |
|---|---|---|
| 左侧最外的 Power | 向电脑发送电源键事件 | 无双功能绑定 |
| 左侧 Power 右边的平键 | Enter 回车 | 进入第 1 层：数字、功能键 |
| 左侧 Enter 右边的斜键 | Esc | 进入第 3 层：导航、媒体 |
| 左侧最靠内的斜键 | 鼠标右键 | 保持鼠标右键按下 |
| 右侧最靠内的斜键 | 鼠标左键 | 保持鼠标左键按下 |
| 右侧鼠标左键右边的斜键 | Backspace 退格，删除光标前的字符 | 进入第 2 层：符号 |
| 右侧退格右边的平键 | Space 空格 | 左 Shift |
| 右侧最外的媒体键 | 播放/暂停 | 无双功能绑定 |

这里的 Power 是电脑收到的电源键事件，实际响应取决于桌面设置，不是键盘本身的电源开关。Studio 把退格命名为 `Keyboard Delete`，把向后删除命名为 `Keyboard Delete Forward`，两者不同。

**切层的正确动作**

1. 按住切层键，稍作停顿。
2. 保持按住，短按目标键；可以连续按多个目标键。
3. 松开切层键，结束这次临时切层。

本配置的五个基础层入口都是 `Layer Tap`：短按执行原键，长按临时启用指定层。具体长按判定时间尚未读取，不要把官方默认值当作这把键盘的实际设置。初学时先停顿一下再按目标键，熟悉后再加快。[ZMK 双功能键说明](https://zmk.dev/docs/keymaps/behaviors/hold-tap)

| 要进入的层 | 按住哪个键 | 松开后的结果 |
|---|---|---|
| 第 1 层 | 左拇指 Enter | 停用第 1 层 |
| 第 2 层 | 右拇指退格 | 停用第 2 层 |
| 第 3 层 | 左拇指 Esc，或者字母 G、H | 停用第 3 层 |

刚开始只使用一个切层键。正常从基础层操作时，松开就回到基础层；如果同时启用了其他层，仍会受那些层影响。ZMK 允许多个层同时启用，编号较高的层优先处理按键；`Transparent` 表示继续使用下层绑定。[ZMK 层行为说明](https://zmk.dev/docs/keymaps/behaviors/layers)

**第 1 层：数字和 F1–F12**

按住左拇指 Enter，按下面的位置。

```text
原位置   Q    W    E    R    T       Y    U    I    O    P
输出     F9   F10  F11  F12  Ins     .    7    8    9    =

原位置   A    S    D    F    G       H    J    K    L    ;
输出     F5   F6   F7   F8   PgUp    -    4    5    6    +

原位置   Z    X    C    V    B       N    M    ,    .    /
输出     F1   F2   F3   F4   PgDn    *    1    2    3    /
```

右拇指退格位置在这一层输出 **0**，空格位置输出 **小数点**。因此输入 `2026` 可以一直按住左拇指 Enter，依次短按：逗号位置、右拇指退格、逗号位置、L。

这里的数字采用普通数字键码；减、加、乘、除采用数字小键盘运算符键码。基础层部分字母的长按修饰键在本层已被功能键覆盖。例如进入第 1 层后，F 的位置是 F8。

**第 2 层：符号和滚动**

按住右拇指退格。以下符号按英文 US 键盘布局解释；电脑切到其他布局或输入法时，最终字符可能不同。

| 目标符号 | 原位置 | 目标符号 | 原位置 |
|---|---|---|---|
| `'` 单引号 | Q | `"` 双引号 | W |
| `!` | E | `*` | R |
| `~` | T | `_` | U |
| 反引号（U+0060） | O | 竖线（U+007C） | P |
| `@` | A | `#` | S |
| `$` | D | `(` | F |
| `)` | G | `[` | J |
| `]` | K | `{` | L |
| `}` | 分号 | `%` | X |
| `^` | V | `\` 反斜杠 | B |
| `&` | N | | |

Y 的位置是向上滚动，H 的位置是向下滚动。

符号绑定已经包含所需的 Shift。例如按住退格后短按 E 就发送感叹号对应组合，不需要再自己按 Shift。Studio 键帽有时只显示底层的 `1`、`8` 等字符；以上表格已计入详情里的 Shift 修饰。

**第 3 层：方向、编辑和媒体**

建议按住左拇指 Esc，右手即可完整使用 H/J/K/L 四个方向位置。

| 原位置 | 输出 | 常见用途 |
|---|---|---|
| H / J / K / L | ← / ↓ / ↑ / → | 移动光标 |
| A / E | Home / End | 移动到行首、行尾，具体由应用解释 |
| D | Delete Forward | 删除光标后的字符 |
| B / F | Ctrl+← / Ctrl+→ | 常用于按词移动 |
| U / I | Ctrl+PageUp / Ctrl+PageDown | 常用于切换标签页，取决于应用 |
| Y / O | 浏览器后退 / 前进 | 浏览历史 |
| W | Alt+Tab | 切换窗口，取决于桌面绑定 |
| Q | Alt+F4 | 关闭窗口，取决于桌面绑定 |
| P / N | 上一曲 / 下一曲 | 媒体控制 |
| M | 静音 | 媒体控制 |
| 逗号 / 句号 | 音量减 / 音量加 | 媒体控制 |
| 斜杠 | 播放/暂停 | 媒体控制 |
| T / G | 左 GUI+F14 | 自定义快捷键，具体用途尚未确认 |

G、H 长按也能进入这一层，但作为切层键保持按下时，不能再用同一个键的位置发出另一个独立按键。因此，想连续使用四个方向，左拇指 Esc 更方便。

**字母键上的 Ctrl、Shift、Alt 和 GUI**

Studio 基础层上看到的 Ctrl、Shift、GUI 等标签，是许多双功能键的长按动作。短按仍然输入字母或标点。

| 短按字符 | 长按动作 | 短按字符 | 长按动作 |
|---|---|---|---|
| A | 左 Alt | M | 左 Alt |
| S | 左 Shift | 逗号 | 左 Shift |
| D | 左 GUI | 句号 | 左 GUI |
| F | 左 Ctrl | 斜杠 | 左 Ctrl |
| J | 右 Ctrl | Z | 右 Ctrl |
| K | 右 GUI | X | 右 GUI |
| L | 右 Shift | C | 右 Shift |
| 分号 | 右 Alt | V | 右 Alt |

GUI 对应常说的 Super/Windows/Command 键，具体快捷键由操作系统解释；右 Alt 在一些布局中用作 AltGr。G/H 的长按动作是第 3 层，空格的长按动作是左 Shift。

练习快捷键时，先按住修饰键位置并稍作停顿，再短按目标字符，最后松开修饰键。例如，在支持 Ctrl+C/Ctrl+V 的编辑器里，可以按住右手 J，再短按左手 C/V。输入大写 A 可以按住右拇指空格，再短按 A。

本机还运行着 keyd，所以以上是键盘固件发送的绑定；桌面快捷键、keyd 和应用仍可能影响最终响应。

**五分钟练习**

打开一个空白文本编辑器，依次做以下练习：

1. 短按输入 `hello world`，空格用右拇指平键；再短按左拇指 Enter 换行。
2. 用右拇指退格短按删除一个字符，感受短按动作。
3. 按住左拇指 Enter，输入 `123`：依次短按 M、逗号、句号；松开 Enter。
4. 按住右拇指退格，输入 `()`：依次短按 F、G；松开退格。
5. 按住左拇指 Esc，短按 H/J/K/L，观察光标移动；松开 Esc。
6. 按住右拇指空格，短按 A，练习输入大写字母。

先熟悉 Enter、退格、Esc 这三个层入口，再练习字母键长按修饰键。若出现意外字母或空格，先放慢双功能键的动作，区分短按和长按。

**在 ZMK Studio 中查键**

打开 [ZMK Studio](https://zmk.studio)，连接 pskeeb5 后，点击左侧层号，再点击具体键位。详情中的 `Behavior` 是行为，`Layer` 是目标层，`Key` 是键码；带有修饰键的绑定还要检查 Shift/Ctrl 等是否选中。

点击左侧层号只是在编辑器里查看该层，不会让实体键盘自动切到该层。只查看时不需要修改字段或保存。Studio 可用于修改键位，设备需支持 Studio；修改解锁使用固件中配置的 Studio Unlock 行为。[ZMK Studio 官方说明](https://zmk.dev/docs/features/studio)

页面实际有第 0–14 层。本手册重点覆盖直接从基础层进入的第 1–3 层。第 4 层还包含蓝牙、鼠标设置和 To Layer 绑定；其实体入口尚未确认。第 5–14 层显示普通字母布局，本次仅额外确认第 5 层原 Power 位置绑定为 To Layer 0，可返回基础层。尚不能据此认定其余层的返回参数相同。

鼠标左右键的含义依据 [ZMK 鼠标行为定义](https://zmk.dev/docs/keymaps/behaviors/mouse-emulation)：MB1 为左键，MB2 为右键。

本说明已核对 Studio 中前四层各键的行为与参数，但尚未完成实体按键逐项测试，也未读取固件中的组合键、条件层、双功能键判定时间和旋钮配置。
